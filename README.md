# To Do List

오늘 할 일에 집중하는 가벼운 투두 리스트. 빌드 도구·프레임워크·서버 없이 **`index.html` 한 파일**로 동작합니다.

**데모:** https://soonupy97.github.io/to-do-list/

## 기획 의도

투두 앱은 대부분 "관리"에 치우쳐 프로젝트·태그·우선순위를 잔뜩 붙입니다. 이 앱은 반대로 **오늘 무엇을 할지**만 남겼습니다.

- 할 일은 마감일 기준으로 자동 정리됩니다: **기한 지남 → 오늘 → 예정 → 날짜 없음 → 완료**
- 입력할 때는 제목 하나와 마감일(오늘 / 내일 / 직접 선택 / 없음)만 정합니다
- 헤더에 "오늘 3개 중 1개 완료"처럼 오늘의 진행 상황만 보여줍니다
- 로그인·서버 없이 브라우저 `localStorage`에 저장됩니다

> **주의: 데이터는 브라우저별로 분리됩니다.** 크롬에 적은 할 일은 삼성 인터넷·사파리·다른 기기에서 보이지 않습니다. 첫 방문 시 앱 안에서도 이 내용을 안내하며, 되도록 한 브라우저에서만 관리하는 것을 권장합니다.

## 기능

| 영역 | 내용 |
|---|---|
| 추가 | 제목 + 마감일 칩(오늘·내일·날짜 선택·없음). 빈 제목은 인라인 오류로 안내 |
| 달력 | 앱과 같은 디자인의 커스텀 캘린더. 데스크톱은 팝오버, 모바일은 바텀 시트. 방향키·Home/End·PageUp/Down·Enter·Esc 키보드 탐색, 오늘·날짜 없음 바로가기 |
| 완료 | 체크박스 토글. 완료 항목은 완료 그룹으로 이동, 다시 눌러 되돌리기 가능 |
| 수정 | 제목을 누르면 인라인 편집(제목·마감일, 같은 캘린더 사용). `Enter` 저장, `Esc` 취소 |
| 삭제 | 항목 삭제 · 완료 항목 일괄 지우기. 6초 동안 **되돌리기** 토스트 제공 |
| 정리 | 마감일 기준 5개 그룹 자동 분류, 기한 지남은 경고색으로 표시 |
| 테마 | 시스템 다크 모드 자동 반영 + 수동 전환(저장됨) |
| 반응형 | 640px 미만에서는 입력창이 하단 고정(엄지 영역), safe-area·온스크린 키보드 높이 반영 |
| 접근성 | 44px 터치 타깃, `role="checkbox"`, 캘린더 `role="grid"` + roving tabindex, 포커스 링, 라이브 리전 안내, 키보드 단축키 `/`, 삭제 후 포커스 유지 |
| 기타 | 자정 넘김·탭 복귀 시 "오늘" 기준 자동 갱신, 다중 탭 동기화, 손상된 저장 데이터 복구 |

## 사용

```bash
git clone https://github.com/soonupy97/to-do-list.git
cd to-do-list
# 그냥 index.html 을 브라우저로 열면 됩니다
```

외부 요청은 폰트 하나뿐입니다(오프라인에서는 시스템 폰트로 동작).

- 폰트: [Pretendard Variable](https://github.com/orioncactus/pretendard) (CDN)
- 아이콘: [Phosphor Icons](https://phosphoricons.com/) 경로 데이터를 SVG 스프라이트로 인라인

## 디자인 메모

- 중립 웜 그레이 베이스 + 강조색 하나(moss green). 기한 지남에만 경고색 사용. 텍스트 4.5:1, UI 경계 3:1 이상 대비(라이트·다크 모두)
- 라운드 규칙: 패널 16px, 상호작용 요소 12px, 소형 컨트롤 10px·8px, 칩은 pill
- 글자 크기는 짝수 px(12 / 14 / 16 / 20 / 24 / 32)만 사용
- 항목 추가·완료·삭제 시 View Transitions API로 위치 이동을 부드럽게 표현. `prefers-reduced-motion`이면 즉시 전환
